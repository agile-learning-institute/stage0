# Exercise Template: Observe/Reflect/Make Structure

Use this template for creating new design chat exercises that follow the Observe/Reflect/Make framework.

## User Journey Mapping
**Purpose**: To map out the complete user journey from initial awareness through post-purchase support, identifying key touchpoints, pain points, and opportunities for improvement.

### Observe
**Instructions**: Document each step in the user journey as you experience or imagine it. For each step, note what the user does, thinks, and feels.
- Keep observations brief - think of what you could write on a 3"x3" sticky with a dull sharpie
- Practice "yes and" thinking, writing, and speaking - add your ideas, don't tear others down
- Give all your ideas, include magical or absurd thinking
- We are Observing as individuals, no discussion or cross-talk during the Observe phase
- Quantity over quality, better 10 crazy ideas than 1 "Best" idea

**Format**: One step per reply in the format: "[Step]: [What user does] → [What user thinks] → [What user feels]"

**Completion Signal**: React with 👍 when you have completed mapping all user journey steps you can think of.

### Reflect
**Instructions**: Synthesize the individual user journey steps into a cohesive journey map. Group related steps into phases and identify common pain points and opportunities.
- Replace placeholder text with synthesized journey map
- Use formatting to indicate patterns, consensus, or groupings
- Build upon previous contributions to create coherent summary
- Look for pain points (negative thoughts/feelings) and opportunities (positive moments that could be enhanced)

**Format**: Create a journey map with phases as level-2 headers (## Phase Name) and steps as bullet points under each phase. Use *italics* for pain points and **bold** for opportunities.

**Completion Signal**: When the synthesized journey map is complete and understood by all participants.

### Make
**Instructions**: Convert the journey map into actionable improvements. Identify the top 3 pain points to address and propose specific improvements for each.
- Propose and agree on concrete outcomes
- Create actionable items: decisions, assignments, schedules, plans
- Document commitments within the exercise post
- Identify quick wins (easy to implement, high impact) and strategic initiatives (more complex, long-term value)

**Format**: 
1. Top 3 Pain Points: List as numbered list with brief description
2. For each pain point: Proposed Improvement, Effort Level (Low/Med/High), Impact Level (Low/Med/High)
3. Quick Wins: Bullet list of improvements that are Low Effort, High Impact
4. Next Steps: Assign owners and timelines for top improvements

**Completion Signal**: When concrete improvements are documented, agreed upon, and clear next steps are established.
